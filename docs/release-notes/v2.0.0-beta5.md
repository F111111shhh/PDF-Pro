# PDF Pro 2.0.0 Beta 5

## 中文

这是一个仅供验收的稳定性测试版。它会覆盖之前安装的 PDF Pro Beta，但不会覆盖正式版，也尚未合并到 `main`。

- 修复拖动批注后立即松手时，屏幕位置与保存位置可能不一致的问题。
- 保存时根据页面实际 CSS 宽高分别换算 PDF 坐标，减少页面尺寸取整造成的偏移。
- 导出批注的额外透明像素不再参与定位，保留批注框原始位置和高度。
- 缓存滚动条尺寸计算，减少无批注页面滚动和缩放时的强制布局读取。
- 长文档最多同时渲染两个附近页面；快速滚动离开范围的页面会取消或丢弃渲染，避免画布累积导致卡顿。
- 保留 Beta 4 的自然字体比例、缩放事件合并和 Beta 3 的完整批注保存修复。

## English

This is a stability-focused test build for review. It updates an installed PDF Pro Beta, remains separate from the stable app, and has not been merged into `main`.

- Fixes annotation coordinates diverging from the saved PDF when a drag is released before the queued frame runs.
- Maps PDF coordinates using the page's actual CSS width and height to reduce rounding drift.
- Keeps extra transparent raster padding out of placement calculations.
- Caches scrollbar dimensions to reduce forced layout work during scrolling and zooming without annotations.
- Limits long-document rendering to two nearby pages and cancels or discards pages left behind during fast scrolling.
- Retains Beta 4's natural font proportions, coalesced zoom input, and Beta 3's complete annotation export fixes.
