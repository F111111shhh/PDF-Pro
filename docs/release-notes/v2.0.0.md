# PDF Pro v2.0.0

## 中文

PDF Pro 2.0 是一次稳健重构版，保留原来的 WebView + PDF.js + pdf-lib 技术路线，同时把核心能力做成本地离线、可维护、可发布的形态。

### 亮点

- 完全本地化 PDF.js、PDF worker 与 pdf-lib，应用启动和打开文档不再依赖 CDN。
- 新增四类批注：文字、高亮、矩形框、签名/手写。
- 保存结果继续写入系统下载目录，文件名采用 `原文件名-PDF-Pro-annotated-时间戳.pdf`。
- 使用更安全的 WebView 本地 HTTPS 资源加载方式，关闭不必要的 file 访问与混合内容加载。
- README、界面与发布说明改为中英双语。
- 新增 GitHub Actions 构建检查。

### 升级说明

如果本次 APK 无法沿用 v1.0.0 的原签名，已安装旧版的用户可能需要先卸载旧版再安装 v2.0.0。

## English

PDF Pro 2.0 is a stable rebuild of the original app. It keeps the WebView + PDF.js + pdf-lib foundation while making the app offline-first, easier to maintain, and safer to release.

### Highlights

- PDF.js, the PDF worker, and pdf-lib are bundled locally, so the app no longer depends on CDN loading.
- Four annotation tools are available: text, highlight, box, and signature/freehand ink.
- Saved files still go to the system Downloads folder with a readable `source-PDF-Pro-annotated-timestamp.pdf` name.
- WebView now loads APK assets through a safer local HTTPS asset loader and disables unnecessary file/mixed-content access.
- README, UI text, and release notes are bilingual.
- GitHub Actions build verification has been added.

### Upgrade Note

If this APK cannot reuse the original v1.0.0 signing key, existing users may need to uninstall the old app before installing v2.0.0.
