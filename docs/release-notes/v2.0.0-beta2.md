# PDF Pro 2.0.0 Beta 2

## 中文

这是一个仅供验收的稳定性测试版，不会覆盖已安装的正式版，也尚未合并到 `main`。

- 测试版包名为 `com.example.pdfpro.beta`，应用名称为 `PDF Pro Beta`。
- PDF.js、PDF worker 和 pdf-lib 已随 APK 本地提供，不需要互联网连接。
- WebView 仅允许加载 APK 内的资源，并关闭文件访问、混合内容和调试能力。
- 修复 Android 16 返回手势，以及 Android 7 至 9 保存到下载目录的兼容问题。
- 保存按钮会等待 Android 返回真实结果，文件名会保留原文件名称并过滤非法字符。
- 长文档改为按可见区域渲染，工具栏与文档区域采用稳定布局，右侧滚动条常驻显示。
- 当前只保留文字批注，不在本测试版中加入高亮、形状和手写功能。

## English

This is a stability-focused test build for review. It installs alongside the stable app and has not been merged into `main`.

- The beta package is `com.example.pdfpro.beta`, labeled `PDF Pro Beta`.
- PDF.js, its worker, and pdf-lib are bundled in the APK for offline use.
- WebView access is limited to packaged assets, with file access, mixed content, and debugging disabled.
- Android 16 back gestures and Android 7-9 Downloads saving are handled correctly.
- The save button waits for the native result, and output names preserve the source name while removing invalid characters.
- Long documents render only nearby pages, the toolbar uses a stable layout, and the right-side scrollbar remains visible.
- This beta keeps text annotations only; highlight, shapes, and freehand tools are intentionally excluded.
