# PDF Pro 2.0.0 Beta 4

## 中文

这是一个仅供验收的稳定性测试版。它会覆盖之前安装的 PDF Pro Beta，但不会覆盖正式版，也尚未合并到 `main`。

- 移除保存批注时的非等比字体缩放，避免部分 Android 设备上的文字被横向压缩。
- 使用标准高分辨率画布坐标绘制文字，在保持清晰度的同时保留字体原始比例。
- 缩放滑块的连续输入合并为每个画面帧最多一次更新，减少大量批注页面上的重复计算。
- 每次缩放只计算一次自定义滚动条布局，并缓存相同字号的字体基线测量结果。
- 保留 Beta 3 的真实换行、完整导出、保存快照和保存期间交互锁定修复。

## English

This is a stability-focused test build for review. It updates an installed PDF Pro Beta, remains separate from the stable app, and has not been merged into `main`.

- Removes non-uniform font scaling during annotation export to prevent horizontally compressed text on some Android devices.
- Uses standard high-resolution canvas coordinates to preserve natural glyph proportions without reducing output clarity.
- Coalesces continuous zoom-slider input to at most one update per animation frame.
- Performs one custom-scrollbar layout update per zoom and caches font baseline measurements by size.
- Retains Beta 3's browser-accurate wrapping, complete export, save snapshots, and interaction locking during save.
