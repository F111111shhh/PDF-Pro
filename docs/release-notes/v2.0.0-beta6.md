# PDF Pro 2.0.0 Beta 6

## 中文

这是一个仅供验收的稳定性测试版。它会覆盖之前安装的 PDF Pro Beta，但不会覆盖正式版，也尚未合并到 `main`。

- 保存批注的位置换算恢复为旧版稳定逻辑：统一使用页面初始缩放比例和批注原始框高。
- 保留拖动松手时强制提交最后坐标的修复，避免拖动竞态导致保存数据落后一帧。
- 保留 Beta 5 的滚动条尺寸缓存和长文档渲染队列优化。

## English

This is a stability-focused test build for review. It updates an installed PDF Pro Beta, remains separate from the stable app, and has not been merged into `main`.

- Restores the stable annotation placement conversion: one initial page scale and the original annotation box height.
- Retains the final-drag-delta commit so a release cannot use a stale position from the previous animation frame.
- Retains Beta 5's cached scrollbar metrics and bounded long-document render queue.
