# PDF Pro 2.0.0 Beta 3

## 中文

这是一个仅供验收的稳定性测试版。它会覆盖之前安装的 PDF Pro Beta，但不会覆盖正式版，也尚未合并到 `main`。

- 修复长批注、中英文混排和大字号批注在保存后偶尔漏字或被裁切的问题。
- 保存时按屏幕上的真实换行结果生成批注，保留显式换行并同步修正导出高度。
- 保存按钮按下后固定使用当时的批注快照，保存过程中的其他状态变化不会污染输出。
- 保存期间暂时锁定文档区域，避免拖动、滚动或新建批注与导出同时发生；保存结束后自动恢复。
- 继续保留 Beta 2 的长文档按需渲染、稳定工具栏和常驻右侧滚动条修复。
- 测试版包名仍为 `com.example.pdfpro.beta`，应用名称仍为 `PDF Pro Beta`。

## English

This is a stability-focused test build for review. It updates an installed PDF Pro Beta, remains separate from the stable app, and has not been merged into `main`.

- Fixes occasional missing or clipped characters in long, mixed-language, and large-font annotations after saving.
- Uses the browser's actual line wrapping when rasterizing annotations and preserves explicit line breaks with the required output height.
- Saves from an immutable annotation snapshot captured when the save button is pressed.
- Temporarily locks document interaction during export, then restores it after completion.
- Retains Beta 2's lazy page rendering, stable toolbar layout, and persistent right-side scrollbar fixes.
- The beta package remains `com.example.pdfpro.beta`, labeled `PDF Pro Beta`.
